# Dotfiles 👾

I love tinkering with my personal and development environment to make it both productive and fun to use.
Feel free to check my setup, comment on it, or grab anything that you find useful, but be aware that it is tailored to my needs!

## Usage

There's a script per system that will install all the packages I use and clone this repository under `~/.config`

- Unix:

```bash
curl -O https://raw.githubusercontent.com/jeangiraldoo/dotfiles/scripts/unix/install.sh
chmod +x install.sh
./install.sh
```

- Windows:

```powershell
curl.exe -O https://raw.githubusercontent.com/jeangiraldoo/dotfiles/scripts/windows/install.ps1
./install.ps1
```
